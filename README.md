StoneHouse — сайт строительной компании

Лендинг для компании по строительству загородных домов премиум-класса под ключ. Адаптивная вёрстка, анимации при скролле, интерактивные элементы — без фреймворков, на чистых HTML/CSS/JS.

🔗 Демо https://dex1tt.github.io/-StoneHouse/

Стек


HTML5 — семантичная вёрстка
CSS3 — Grid, Flexbox, кастомные свойства (CSS Variables), анимации
JavaScript (Vanilla) — без библиотек и фреймворков
Intersection Observer API — анимации появления при скролле, счётчики, активные пункты меню


Функциональность


🍔 Адаптивное бургер-меню — выезжает сверху на мобильных устройствах
✨ Scroll-reveal анимации — секции и карточки плавно появляются при прокрутке, с каскадным эффектом задержки
🔢 Анимированные счётчики — цифры в статистике плавно "накручиваются" при попадании в область видимости
🎯 Активный пункт навигации — подсвечивается автоматически в зависимости от текущей секции при скролле
⬆️ Кнопка "наверх" — появляется после прокрутки, плавный скролл к началу страницы
✅ Валидация формы — проверка имени и телефона на клиенте, состояние успешной отправки
📱 Полностью адаптивен — брейкпоинты для планшетов (900px) и мобильных (480px)
🎨 Единая дизайн-система — CSS-переменные для цветов, переиспользуемые паттерны карточек с hover-эффектами


Структура секций


Hero — заглавный экран с фоновым изображением и CTA-кнопками
Преимущества — карточки с ключевыми показателями компании + фото
Услуги — три направления работы компании
Портфолио — асимметричная сетка построенных объектов
Процесс работы — таймлайн из 5 этапов сотрудничества
Статистика — анимированные показатели компании
Отзывы — карточки с отзывами клиентов
Контакты — форма заявки с валидацией
Футер — контактная информация и навигация
